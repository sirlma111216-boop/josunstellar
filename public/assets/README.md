# assets 폴더 — 이미지 자료

파일이 없어도 앱은 죽지 않고 "교사용: assets 폴더에 넣어 주세요" 안내를 보여 준다.

### 지도 — 앱이 반드시 필요로 하는 것

| 파일명 | 규격 | 쓰이는 곳 |
|---|---|---|
| `chart_orion.webp` | 2280 × 2480, 흑백, 0.59 MB | **각석본** — 단계 4·5·8, 측정에 사용 |
| `chart_color.webp` | 2280 × 2480, 컬러, 0.73 MB | **채색본** — 단계 5 비교 |
| `chart_full.webp` | 540 × 622, 0.11 MB | 전체 지도 — 단계 1 배경, 단계 4 줌인, 미니맵 |

### 수업 자료 — 교사가 넣는 것

| 파일명 | 쓰이는 곳 | 없으면 |
|---|---|---|
| `chart_stone.jpg` `bill.webp` | 단계 3 이야기 카드 | 카드 자리가 빈다 |
| `2-2.webp` `2-3.webp` `2-5.webp` | 단계 3 이야기 카드 삽화 | 카드 자리가 빈다 |
| `star.webp` | 단계 7-2 밤하늘 사진 | 그림 자리가 빈다 |
| `hipa.webp` `grade.jpg` | 단계 7-3·7-5 등급 설명 | 그림 자리가 빈다 |
| `Athens.webp` `pthol.webp` | 단계 7-3 「아테네 학당」 전체·부분 | 그림 자리가 빈다 |
| `moon.webp` | **단계 6 「월하정인」** | 안내 문구가 뜨고 수업은 진행된다 |
| `bgm.mp3` | 배경음악(기본 꺼짐, 반복 재생) | 음악 단추가 조용히 접힌다 |

`moon.webp` 와 영상 주소는 `?admin=1` → 교사 설정 → **④ 수업 자료** 에서 바꿀 수 있다.
그림을 같은 이름으로 갈아 끼웠는데 옛 그림이 보이면, 이미지가 7일 캐시라
`js/steps.js` 의 `PIC_V` 숫자를 올린다.

## 두 지도는 같은 좌표계다

`chart_orion.jpg`와 `chart_color.jpg`는 **완전히 같은 영역을 같은 축척으로 자른 것**이다.
같은 (x, y)가 두 지도에서 같은 별을 가리키므로, 앱은 좌표 변환 없이
겹치기·밀어보기·같은 위치 동시 확대를 구현한다.
**두 파일을 교체할 때는 이 대응이 깨지지 않도록 반드시 같은 영역·같은 축척으로 자를 것.**

## 각석본 상세

- 보물 「복각천상열차분야지도 각석」(1687)의 원형기록 사진에서
  삼수(오리온) 일대를 잘라 배경 얼룩을 제거하고 2배 확대한 것.
- 별 자국 지름은 이 이미지 안에서 대략 **8 ~ 60 px**.
  측정 뷰는 자국이 화면에서 최소 60px로 보이도록 3~14배로 확대한다
  (`js/constants.js` 의 `MARK_PX` 와 `measureZoom`).

## 전체 지도 교체 안내

`chart_full.webp`는 540 × 622로 작다. 단계 1 배경과 미니맵에는 충분하지만,
단계 4에서 약 4.7배 확대하는 동안에는 흐릿하게 보인다
(확대가 끝나면 선명한 각석본으로 넘어가므로 잠깐이다).
더 선명하게 하고 싶으면 **같은 파일명**으로 고해상도 전체 지도를 넣으면 된다.
넣은 뒤 `?admin=1` 의 **② 단계 4 확대 영역**을 다시 맞춘다.

## 성능

그림은 모두 **WebP** 다. 원본(PNG·JPEG) 합계 13.0 MB 를 **2.7 MB** 로 줄였다.
지도 두 장은 측정 좌표의 기준이라 **크기를 그대로 두고 품질만 92** 로 다시 인코딩했고,
삽화는 품질 86 에 가로 1600 px 로 맞췄다.

첫 로드에는 `chart_full.webp`(0.11 MB)만 받는다.
각석본·채색본은 해당 단계에 처음 들어갈 때 받는다(지연 로드).

**지도 두 장의 픽셀 크기(2280 × 2480)는 바꾸면 안 된다.** 측정 핀이 정규화 좌표로
저장되어 있고 `constants.js` 의 `MARK_PX` 가 이 크기 안의 픽셀 값이라, 크기를 줄이면
잰 값이 달라진다. 다시 인코딩할 때 `resize` 를 걸지 말 것.

## 배경음악

`bgm.mp3` — 「순환하는 은하」(교사 제작, Suno). 4분 51초를 **반복 재생**한다.
원본 185 kbps·6.5 MB 를 **VBR 82 kbps·2.9 MB** 로 다시 인코딩하고 앨범아트를 뺐다.
제목과 만든 이 정보는 태그에 남겨 두었다.

기본이 꺼짐이라 **음악을 켠 기기만** 내려받는다. 더 줄이려면 모노(64 kbps ≈ 2.2 MB)로
바꾸거나, 어차피 반복 재생이므로 앞부분만 잘라 쓰면 된다.

```bash
ffmpeg -i bgm.mp3 -vn -c:a libmp3lame -q:a 7 -ar 44100 -map_metadata 0 out.mp3
```
화질이 견딘다면 JPEG 품질을 낮춰 1 MB 이하로 줄이는 편이 낫다.
