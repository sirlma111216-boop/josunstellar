# assets 폴더 — 교사가 넣을 이미지

아래 파일 이름 그대로 이 폴더에 넣어 주세요. 파일이 없어도 앱은 죽지 않고
"교사용: assets 폴더에 이미지를 넣어 주세요" 안내를 보여 줍니다.

| 파일명 | 필수 | 쓰이는 곳 | 비고 |
|---|---|---|---|
| `chart_orion.jpg` | ✅ 필수 | 겹쳐보기 · 측정 탐구대 | 천상열차분야지도의 **삼수(參宿) 영역 고해상도 크롭** |
| `chart_full.jpg` | 선택 | 겹쳐보기 도입 | 전체 지도 |
| `suzhou.jpg` | 선택 | 비교 카드(4단계) | 중국 순우천문도(1247) |

## 준비 요령

- **해상도**: 별 점의 지름을 재는 활동이므로 별 하나가 화면에서 최소 20px 이상으로
  보이도록 넉넉히 큰 이미지를 쓰세요. 다만 저사양 태블릿을 고려해 **긴 변 2000px 안팎,
  파일 크기 1MB 이하**(JPEG 품질 80 정도)로 줄이는 것을 권합니다.
- **자르기**: 대략만 잘라 두고, 정밀한 자르기·회전·좌우반전은 앱의
  캘리브레이션 모드(주소 뒤에 `?admin=1`)에서 맞추면 됩니다.
- **출처 표기**: `assets/js/constants.js` 의 `APP.IMAGE_CREDIT` 값을 실제 출처와
  공공누리 유형에 맞게 반드시 수정하세요. 이 문구가 화면 하단 푸터에 표시됩니다.
