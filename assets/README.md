# assets 폴더 — 이미지 자료

세 파일이 들어 있다. 파일이 없어도 앱은 죽지 않고
"교사용: assets 폴더에 이미지를 넣어 주세요" 안내를 보여 준다.

| 파일명 | 규격 | 쓰이는 곳 |
|---|---|---|
| `chart_orion.jpg` | 2280 × 2480, 흑백, 1.26 MB | **각석본** — 단계 3·4·6, 측정에 사용 |
| `chart_color.jpg` | 2280 × 2480, 컬러, 1.37 MB | **채색본** — 단계 4 비교 |
| `chart_full.jpg` | 540 × 622, 0.29 MB | 전체 지도 — 단계 1 배경, 단계 3 줌인, 미니맵 |

## 두 지도는 같은 좌표계다

`chart_orion.jpg`와 `chart_color.jpg`는 **완전히 같은 영역을 같은 축척으로 자른 것**이다.
같은 (x, y)가 두 지도에서 같은 별을 가리키므로, 앱은 좌표 변환 없이
겹치기·밀어보기·같은 위치 동시 확대를 구현한다.
**두 파일을 교체할 때는 이 대응이 깨지지 않도록 반드시 같은 영역·같은 축척으로 자를 것.**

## 각석본 상세

- 보물 「복각천상열차분야지도 각석」(1687)의 원형기록 사진에서
  삼수(오리온) 일대를 잘라 배경 얼룩을 제거하고 2배 확대한 것.
- 별 자국 지름은 이 이미지 안에서 대략 **8 ~ 60 px**.
  측정 뷰는 자국이 화면에서 최소 60px로 보이도록 3~14배로 확대한다
  (`js/constants.js` 의 `MARK_PX` 와 `measureZoom`).

## 전체 지도 교체 안내

`chart_full.jpg`는 540 × 622로 작다. 단계 1 배경과 미니맵에는 충분하지만,
단계 3에서 약 4.7배 확대하는 동안에는 흐릿하게 보인다
(확대가 끝나면 선명한 각석본으로 넘어가므로 잠깐이다).
더 선명하게 하고 싶으면 **같은 파일명**으로 고해상도 전체 지도를 넣으면 된다.
넣은 뒤 `?admin=1` 의 **② 단계 3 확대 영역**을 다시 맞춘다.

## 성능

첫 로드에는 `chart_full.jpg`(0.29 MB)만 받는다.
각석본·채색본은 해당 단계에 처음 들어갈 때 받는다(지연 로드).
첫 화면 전송량은 약 **440 KB**.

각석본·채색본이 각각 1.3 MB 안팎이라 학교망이 느리면 단계 3·4 진입이 더딜 수 있다.
화질이 견딘다면 JPEG 품질을 낮춰 1 MB 이하로 줄이는 편이 낫다.

## 출처 표기

`js/constants.js` 의 `APP.CREDIT` 이 화면 하단 푸터와 인쇄물에 그대로 표시된다.
자료를 바꾸면 이 문구도 함께 고칠 것.
