# 별지기 1395

중학교 3학년 「별과 우주」 단원 **수업 두 차시(각 45분)를 처음부터 끝까지 진행하는 학습 도구**.
단순 측정 도구가 아니라, 교사가 화면을 순서대로 넘기면 그것이 곧 수업이 되도록 만들었다.

국보 **천상열차분야지도**를 소재로, 학생이 별 자국의 크기를 직접 재어
"밝은 별일수록 크게 새겼다"는 규칙을 스스로 발견한다.

## 8단계 진행

| 단계 | 화면 | 하는 일 |
|---|---|---|
| 1 | 인트로 | "1395년, 조선. 망원경은 아직 없었다…" 문구가 순서대로 뜬다 |
| 2 | 지도 소개 | 무엇인가 / 얼마나 대단한가 / 만원권 뒷면 — 카드 3장 |
| 3 | 확대해 들어가기 | 전체 지도에서 삼수 영역으로 **줌인 애니메이션**. 이후 미니맵 상시 표시 |
| 4 | **두 지도 비교** | 채색본(크기 같음) ↔ 각석본(크기 다름), 같은 별 3개 확대 대조, 밀어보기, 예상 고르기 |
| 5 | 겉보기 등급 | 밝기 차이 → 그리스식 등급 → **"숫자가 작을수록 밝다"** → 0·마이너스 등급 |
| 6 | 측정하기 | 핀 12개, 확대 측정 뷰, 두 손잡이로 지름 재기, 2차 측정·평균 |
| 7 | 결과 확인 | 표 → 점 그래프(애니메이션) → "이런 걸 산점도라고 한다" → 경향선 |
| 8 | 결론 | 내 결론 쓰기 → 정리 문구 → 두 지도의 의미 → 예상 되돌아보기 → 다음 시간 예고 |

교사는 단계 표시줄로 어느 단계로든 즉시 건너뛸 수 있고,
설명 중심 화면(2·3·4·7)에는 작은 [건너뛰기 ▸] 버튼이 있다.

## 특징

- **정적 단일 페이지 앱** — 서버·로그인·외부 API·CDN 없음. GitHub Pages에 그대로 올리면 된다.
- **학생 데이터는 기기 밖으로 나가지 않는다** — 진행 상태와 측정 기록은 localStorage에만.
- 바닐라 HTML/CSS/JS. 그래프·도식·삽화까지 전부 **SVG로 직접 그린다.**
- 터치 우선(버튼·손잡이 44px 이상), 화면 확대 방해 없음, 글자 크기 3단계.
- 새로고침해도 이어서 진행된다. 도움말 안의 [전체 초기화]로 리셋.
- 정보를 색에만 기대지 않는다(완료 핀은 ✓, 집계는 숫자 병기).

## 두 지도가 같은 좌표계를 쓴다

`chart_orion.jpg`(각석본)와 `chart_color.jpg`(채색본)는 **같은 영역을 같은 축척으로 자른 것**이다.
따라서 같은 (x, y)는 두 지도에서 같은 별을 가리킨다.
앱은 이 점을 그대로 이용해 **좌표 변환 없이** 겹치기·밀어보기·같은 위치 동시 확대를 구현한다.
단계 4에서 두 장면의 별 3개 확대창은 좌표도 배율도 완전히 같고 이미지 파일만 다르다.

## 무엇을 재는가 (측정 기준)

원본 유물을 확대해 보면 **밝은 별일수록 크고 깊게 파여 가운데가 비고 테두리만 진한 "고리"**로 보인다.
어두운 별은 작고 속이 찬 점에 가깝다. 따라서 측정 대상은 '가장 긴 지름'이 아니라
**바깥 테두리의 바깥쪽 끝에서 끝까지의 지름**이다.
앱은 이 기준을 코드로 그린 고리 도식과 함께 측정 화면·도움말·인쇄물에서 안내한다.

측정 뷰의 확대 배율은 자국이 화면에서 **최소 60px 이상**으로 보이도록 자동으로 잡는다
(자국 8~60px → 3~14배).

## 인쇄

- **[나의 탐구 보고서 만들기]** — 이름·모둠을 입력하면 탐구 질문 / 나의 예상 / 측정 결과 표 /
  그래프 / 내 결론 / 오늘의 정리 / 출처가 담긴 A4 보고서를 브라우저 인쇄로 뽑는다.
  PDF 저장은 인쇄 대화상자에서 고르면 된다.
- **[빈 기록표 인쇄]** — 태블릿이 없는 학급용. 측정 기준 도식 + 빈 기록표 + 빈 모눈 그래프.
- **교사용 CSV** — 12개 별의 1차·2차·평균과 학생의 예상·결론까지. 엑셀 한글 깨짐 방지 BOM 포함.

## 교사 준비 순서

주소 뒤에 **`?admin=1`** 을 붙이면 캘리브레이션 모드로 들어간다.

1. **① 측정 핀 12개** — 지도에서 핀을 끌어 별 자국 한가운데로 옮긴다.
   핀을 고르면 확대 창이 열리고, 창 안을 끌면 원본 픽셀 단위로 미세 조정된다.
   허리띠 세 별(8·9·11)처럼 겹친 핀은 같은 자리를 반복해 누르면 차례로 선택된다.
   [예상 위치로 초기화]로 언제든 되돌릴 수 있다.
2. **② 단계 3 확대 영역** — 전체 지도에서 삼수 자리에 사각형을 맞춘다.
   ⚠ 기본값은 눈으로 확인하지 않은 어림값이므로 **반드시 확인이 필요하다.**
   맞춘 뒤 "이 영역을 눈으로 확인함"을 켠다.
3. **③ 단계 4 별 3개** — 크기 차이가 잘 드러나는 밝은·중간·어두운 별을 고른다.
4. **[config.json 내보내기]** → 내려받은 파일을 저장소 최상위에 두고 배포한다.
   한 대에서만 쓸 거면 [이 기기에 저장]만 눌러도 된다.

설정 우선순위는 **`config.json` → localStorage → 기본값**.
"config.json 보다 이 기기 설정을 우선 사용"을 켜면 그 기기에서는 localStorage가 이긴다.

## 개발용 서버

```bash
node tools-serve.js 8123
```

`tools-serve.js`는 개발 편의용이며 배포에는 필요 없다.

- 핀 12개의 기본 좌표는 근사값이라 실제 자국과 100~300px 어긋날 수 있다.
  학생 화면에는 교사가 확정한 좌표만 쓰인다.
