# 별지기 1395

중학교 3학년 「별과 우주」 단원 수업용 웹앱.
국보 **천상열차분야지도**(1395)를 활용해 ① 전통 별자리 **삼수**와 **오리온자리**가 같은 별임을
확인하고(1차시), ② 별 점의 지름을 재어 현대 **겉보기 등급**과 비교하는 산점도로
"밝은 별일수록 크게 새겼다"는 규칙을 발견한다(2차시).

## 무엇을 재는가 (측정 기준)

원본 유물을 확대해 보면 **밝은 별일수록 크고 깊게 파여 가운데가 비고 테두리만 진한
"고리" 모양**으로 보인다. 어두운 별은 작고 속이 찬 점에 가깝다.
따라서 측정 대상은 '가장 긴 지름'이 아니라
**바깥 테두리의 바깥쪽 끝에서 끝까지의 지름**이다.
앱은 이 기준을 측정 탐구대 상단의 도식(코드로 그린 SVG)과 도움말에서 함께 안내한다.

## 특징

- **정적 단일 페이지 앱** — 서버·로그인·외부 API·CDN 없음. GitHub Pages에 그대로 올리면 된다.
- **학생 데이터는 기기 밖으로 나가지 않는다** — 측정 기록은 localStorage에만 저장.
- 바닐라 HTML/CSS/JS, 차트도 SVG로 직접 그린다.
- 태블릿 터치 우선(버튼 44px 이상), 화면 확대 방해 없음, 글자 크기 3단계.

## 폴더 구조

```
index.html
assets/
  style.css
  js/constants.js   앱 문구 · 별 12개 데이터 · 성도↔지도 정합 계산
  js/guide.js       측정 기준 문구 + 고리 모양 도식(SVG)
  js/config.js      설정(캘리브레이션) 로드·저장
  js/mapview.js     지도 뷰 (이미지 + 현대 성도 SVG + 측정 핀), 좌표 변환
  js/admin.js       교사 캘리브레이션 패널 + 핀 확대 미리보기
  js/app.js         탭 · 도움말 · 글자 크기 · 초기화
  chart_orion.jpg   2280 × 2480 px 흑백 (assets/README.md 참고)
config.json         ← (선택) 캘리브레이션 결과를 내보내 여기에 둔다
```

## 좌표 기준

측정 핀과 현대 성도 레이어는 화면이 아니라 **원본 이미지 픽셀**을 기준으로 저장한다
(설정 `version: 2`). 그래야 교사가 나중에 자르기·회전·좌우반전을 고쳐도
확정해 둔 핀이 그대로 따라 움직인다. 화면에 그릴 때만
자르기 → 확대 → 좌우반전 → 회전 순서로 프레임 좌표로 옮긴다.

현대 성도 레이어의 기본 정렬은 별 12개의 (성도 좌표 → 이미지 픽셀) 대응에서
최소제곱 닮음변환을 구해 자동으로 잡는다.
**삼수 8개** 기준이 기본값이며 허리띠 세 별이 4~20px 오차로 맞는다.
옛 지도는 북극 중심 투영이라 극에서 먼 시리우스·프로키온은 원리상 함께 맞지 않으므로,
필요하면 캘리브레이션에서 **전체 12개** 기준으로 바꿀 수 있다.

## 교사 준비 순서

1. `assets/` 에 천문도 이미지를 넣는다 → [assets/README.md](assets/README.md)
2. `assets/js/constants.js` 의 `APP.IMAGE_CREDIT` 를 실제 출처·공공누리 유형으로 고친다.
3. 주소 뒤에 **`?admin=1`** 을 붙여 캘리브레이션 모드로 들어간다.
   - 이미지 자르기·회전·좌우반전을 맞춘다.
   - 현대 성도 레이어를 지도의 삼수와 겹치도록 이동·배율·회전한다.
   - 측정 핀 12개를 별 점 위로 끌어다 놓는다.
4. **[config.json 내보내기]** → 내려받은 파일을 저장소 최상위에 두고 배포한다.
   (한 대에서만 쓸 거면 **[이 기기에 저장]** 만 눌러도 된다.)

설정 우선순위는 **`config.json` → localStorage → 기본값** 이다.
교사가 "config.json 보다 이 기기 설정을 우선 사용"을 켜면 그 기기에서는 localStorage가 이긴다.
